# Dashboard API

## Weekly Brief Data

The Command Center compiles a weekly brief including:

| Component | Description |
|-----------|-------------|
| Period | Brief period boundaries |
| Headline Metrics | Key KPIs (ARR, pipeline, win rate, etc.) |
| Top Priorities | Ranked account priorities |
| Upcoming Renewals | Renewals in the next 30 days |
| Pipeline Summary | Total, weighted, commit, best case pipeline |
| Starbridge Highlights | Notable district intelligence signals |

## Org Metrics

```
POST /api/org-metrics/compute
```

Triggers computation of org-level metrics (ARR waterfall, efficiency ratios, headcount metrics).

## Budget Variance

```
GET /api/budget-variance
```

Returns budget vs actual variance data for the Revenue Economics dashboard.

## Territory Economics

```
GET /api/territory-economics
```

Returns territory-level P&L data including cost-to-yield ratios and headcount impact.
