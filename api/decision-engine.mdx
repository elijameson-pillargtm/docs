# Decision Engine API

The Decision Engine API synthesizes signal data, territory economics, role economics, pipeline cohorts, and headcount planning into strategic decisions with financial modeling.

## GET `/api/decision-engine`

Returns the full Decision Engine output: territory health scores, financial cascades, rebalance recommendations, board scenarios, and rep performance KPIs.

**Auth:** Requires authenticated session. Scoped to org via `org_id`.

**Access:** `cro_ceo`, `vp_sales`, `revops`

### Side Effects

On every GET request, the Decision Engine persists territory health scores to `sam_territories`:

| Column | Type | Description |
|--------|------|-------------|
| `health_score` | INTEGER | Composite territory health (0-100) |
| `health_status` | VARCHAR | `healthy`, `caution`, or `critical` |
| `health_components` | JSONB | Five dimension scores |
| `health_computed_at` | TIMESTAMP | When last computed |

This is a non-blocking write-back so other dashboards can read territory health without calling the full Decision Engine.

## POST `/api/decision-engine`

What-if modeling — propose a change and see the projected financial impact.

**Body:**

```json
{
  "action": "reassign_accounts",
  "params": {
    "from_owner_id": "uuid",
    "to_owner_id": "uuid",
    "account_ids": ["uuid", "uuid"]
  }
}
```

### Actions

#### `reassign_accounts`

Model moving accounts between territories.

**Params:** `from_owner_id`, `to_owner_id`, `account_ids`

**Response:** Before/after territory health, pipeline coverage change, cost-to-yield shift.

#### `add_headcount`

Model adding a new hire to a territory.

**Params:** `role_type` (ae, csm, sdr), `territory_id`

**Response:**

```json
{
  "action": "add_headcount",
  "role_type": "ae",
  "territory_name": "California",
  "fully_loaded_cost": 239000,
  "current_territory_health": 58,
  "revenue_optimistic": 1020000,

  "revenue_pessimistic": 540000,
  "roi_optimistic": 3.27,
  "roi_realistic": 2.26,
  "roi_pessimistic": 1.26,
  "breakeven_month": 8,
  "projected_health_after": 65
}
```

### Data Dependencies

The Decision Engine queries these tables in parallel:

| Table | Fields Used |
|-------|-------------|
| `sam_territories` | Territory definitions, costs, customer ARR, SAM ARR |
| `accounts` | Health scores, ARR, risk scores, owner, territory |
| `opportunities` | All stages (including Closed Lost for win rates) |
| `signals` | Active/acknowledged/in-progress signals |
| `users` | Quotas, roles, active status |
| `role_economics` | Fully loaded costs by role type |
| `renewals` | Risk scores, dispositions |
| `org_metrics` | Current/previous period ARR, NRR |
| `pipeline_cohorts` | Historical win rates by quarter |
