# PILLAR Data Reference

PILLAR is an AI-native Go-To-Market Operating System that connects CRM data, district intelligence, and revenue economics into a unified scoring and signal engine.

This reference documents the key concepts, features, and integrations in the PILLAR platform.

## Data Sources

| Source | Type | Sync | Data |
|--------|------|------|------|
| Salesforce | CRM | Every 15 min | Accounts, Contacts, Opportunities, Leads |
| HubSpot | CRM | Every 15 min | Accounts, Contacts, Deals, Tickets |
| Microsoft Dynamics 365 | CRM | Every 15 min | Accounts, Contacts, Opportunities, Leads, Incidents |
| Google Workspace | Email/Calendar | Per-user | Activities (email metadata, calendar events) |
| Microsoft 365 (Outlook) | Email/Calendar | Per-user | Activities (Outlook metadata, Teams calendar events) |
| Microsoft Teams | Notifications | Push | Signal alerts, daily digests, play notifications via Adaptive Cards |
| Slack | Notifications | Real-time | Signal routing, weekly digest |
| Starbridge.ai | District Intelligence | On-demand + webhook | 120+ buyer attributes, RFPs, contracts, job changes |
| PILLAR Engine | Computed | Continuous | Health scores, risk scores, signals, plays |
