# Revenue Impact

Revenue Impact is PILLAR's attribution engine. It traces every dollar the platform touched back to the signal that surfaced it, the play that acted on it, and the outcome that resulted.

## Why It Matters

The question every CRO asks: "How do I know this is working?" Revenue Impact answers with auditable, timestamped attribution -- not estimates, not correlations, but a direct chain from signal to action to outcome.

## Attribution Chain

Every tracked intervention follows this chain:

```
Signal Generated → Play Triggered → Tasks Executed → Outcome Logged
```

Each link is timestamped and stored, creating a complete audit trail from detection to resolution.

## KPI Metrics

The Revenue Impact dashboard computes:

| Metric | Description |
|--------|-------------|
| **Total Revenue Impact** | ARR Protected + Expansion ARR |
| **ARR Protected** | Renewal ARR saved through signal-triggered save plays |
| **Expansion ARR** | Closed-won expansion/upsell opportunities where a PILLAR signal preceded the deal |
| **Save Rate** | Success rate for renewals with active save plays |
| **Avg Days Early** | Average days between signal generation and renewal date |
| **Pipeline Influenced** | Open opportunities where a PILLAR signal exists on the same account |
| **ARR In Progress** | At-risk renewal ARR with active save plays currently running |

## API Endpoint

```
GET /api/revenue-impact
```

Returns KPI metrics, signal distribution by family and severity, play status counts, and the full attribution chain with expandable account detail.

## Expandable Attribution Rows

Each row in the attribution chain can be expanded to show:
- **Account summary** -- ARR, health score, risk score, renewal date
- **Signal detail** -- Full explanation text and recommended action
- **Play tasks** -- Checklist with completion status and dates

## Access

Available to: CRO/CEO, VP Sales, VP CS, RevOps

Navigate to: `/impact` or click "Revenue Impact" in the Command Center nav pills.
