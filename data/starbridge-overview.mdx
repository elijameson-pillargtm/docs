# Starbridge Integration

Starbridge.ai provides district intelligence for school districts, higher education institutions, and government entities. PILLAR ingests 120+ buyer attributes to enrich account records and drive scoring, signals, and strategic intelligence.

## Connecting Starbridge

Customers connect their own Starbridge API key through the PILLAR Settings UI:

1. Navigate to **Settings > Integrations**
2. Find **Starbridge** under the Enrichment section
3. Click **Connect**
4. Paste your Starbridge API key in the modal
5. Click **Save & Connect**

The key is encrypted and stored per-organization. PILLAR never exposes the raw key after initial entry. Each organization manages their own Starbridge relationship -- PILLAR is the consumption layer, not the data source.

## Data Flow

1. **Initial Sync**: When an account is matched by Starbridge buyer ID or NCES ID, a full attribute pull enriches the account record with 120+ fields
2. **Webhook Updates**: Real-time notifications for job changes, RFP publications, budget shifts, and document postings
3. **On-Demand Refresh**: Manual or scheduled re-sync via the "Sync Now" button in Settings > Integrations
4. **Signal Generation**: Starbridge data changes trigger signals across multiple families

## Data Categories

| Category | Description | Sync |
|----------|-------------|------|
| Buyer Attributes | Budget, enrollment, scores, demographics (80+ fields) | On-demand + webhook |
| Job Changes | Departures, hires, promotions | Webhook (real-time) |
| Contracts | Public contract records | On-demand |
| Purchase Orders | Line-item procurement data | On-demand |
| Conferences | EdTech conference intelligence | Periodic |
| RFPs | Bids and solicitations | Webhook (real-time) |
| Documents | Board minutes, strategic plans | On-demand |
| Competitor Contracts | Competitive spend intelligence | On-demand |

## Scoring Impact

Starbridge data feeds into multiple scoring categories including Fit (technology spending, AI adoption, budget capacity, procurement complexity), Intent (grant funding, competitive windows, RFP activity, strategic alignment), Risk (budget trends, market context), Forecast Confidence (procurement alignment), and Renewal Risk (market context).

## Signal Types from Starbridge

Starbridge events generate signals across multiple families:

| Signal | Description |
|--------|-------------|
| Competitive Displacement Window | Competitor contract approaching expiration |
| RFP Active | Active solicitation detected |
| Board Discussion Relevant | Product-relevant board discussion detected |
| Strategic Alignment | District priorities match your product |
| Grant Funding Available | Grant funding opportunity detected |
| Budget Shift Detected | Significant budget change at the institution |
| Hiring Intent | Relevant hiring activity detected |
| Stakeholder Departure | Key contact departed (higher severity if champion) |
| Procurement Pathway Update | Cooperative purchasing pathway changes |
| Conference Engagement | Relevant conference activity |
